## 🚀 Getting Started (Quick Start)

### 1. Start Backend (Terminal 1)
```bash
cd backend
npm install  # First time only
npm start
```

### 2. Start Frontend (Terminal 2)
```bash
cd frontend
npm install  # First time only
npm start
```

### 3. Open in Browser
```
http://localhost:3000
```

**That's it!** Your Recipe App is now running.
